    1. Install @upstash/redis: `npm install @upstash/redis`

    2. Create src/lib/redis.ts:
    - Import Redis from @upstash/redis
    - Export lazy-initialized redis client (same pattern as lazy Stripe/OpenAI — see Phase 5 decisions):
      ```typescript
      let _redis: Redis | null = null;
      function getRedis(): Redis | null {
        if (!process.env.UPSTASH_REDIS_REST_URL || !process.env.UPSTASH_REDIS_REST_TOKEN) return null;
        if (!_redis) _redis = new Redis({ url: process.env.UPSTASH_REDIS_REST_URL, token: process.env.UPSTASH_REDIS_REST_TOKEN });
        return _redis;
      }
      ```
    - Export async function cacheGet<T>(key: string): Promise<T | null> — returns parsed value or null
    - Export async function cacheSet(key: string, value: unknown, ttlSeconds: number): Promise<void> — sets with EX
    - Export async function cacheWrap<T>(key: string, ttlSeconds: number, fn: () => Promise<T>): Promise<T>:
      - Try cacheGet; if hit, return cached
      - If miss or Redis unavailable, call fn(), store result via cacheSet, return result
      - Wrap entire Redis interaction in try/catch — if Redis is down, fall through to fn() silently (degraded but functional)
    - Export function buildCacheKey(prefix: string, params: Record<string, unknown>): string — deterministic key from sorted JSON
