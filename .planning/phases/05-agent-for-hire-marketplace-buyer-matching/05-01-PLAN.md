       - agentProfiles: id, userId (FK users), firstName, lastName, licenseStates (text[]), licenseNumber, stripeAccountId (nullable), stripeOnboardingComplete (boolean default false), verified (boolean default false), availableForDispatch (boolean default false), flatFeeCents (integer), bio (text nullable), createdAt, updatedAt
       - agentLicenseChecks: id, agentId (FK agentProfiles), state (text), method ('arello'|'manual'), arelloResult (text nullable JSON), verified (boolean), verifiedAt (timestamp), expiresAt (timestamp nullable), createdAt
       - agentRequests: id, transactionId (FK transactions), agentId (FK agentProfiles nullable), state (text), status ('pending'|'accepted'|'completed'|'cancelled'), requestedAt (timestamp), acceptedAt (timestamp nullable), completedAt (timestamp nullable)
       - buyerEvents: id, userId (text), eventType (text), listingId (text nullable), metadata (text — JSON blob), occurredAt (timestamp)

    2. Create raw SQL migrations:
       - migrations/0005_add_agent_tables.sql: CREATE TABLE for agentProfiles, agentLicenseChecks, agentRequests, buyerEvents with appropriate indexes (agentProfiles.userId, agentRequests.transactionId, agentRequests.state+status, buyerEvents.userId+occurredAt)
       - migrations/0006_add_listing_embedding.sql: ALTER TABLE listings ADD COLUMN embedding vector(1536) — pgvector already enabled from Phase 2

    3. Add to src/lib/constants.ts:
       - AGENT_FOR_HIRE_FEE_CENTS = 50000 (i.e., $500 flat fee)

    4. Create src/services/agent/agent-profile.ts:
       - createAgentProfile(data): Insert agent row, call stripe.accounts.create({ type: 'express' }), store stripeAccountId. Return profile.
       - getAgentProfile(userId): Select agent profile with latest license check status.
       - updateAgentProfile(agentId, data): Update mutable fields (bio, licenseStates, availableForDispatch).
       - Use Stripe SDK: `import Stripe from 'stripe'; const stripe = new Stripe(process.env.STRIPE_SECRET_KEY!);`

    5. Create src/services/agent/license-verification.ts:
       - verifyAgentLicense(agentId, state, method): If method='manual', insert agentLicenseChecks row with verified=true. If method='arello', call ARELLO LVWS v2 API (POST XML to ARELLO_API_URL with Basic auth from ARELLO_API_CREDENTIALS), parse response for license status, insert check row. Update agentProfiles.verified=true if any check is verified.
       - ARELLO fallback: If ARELLO_API_URL env var is not set, throw error with message "ARELLO not configured — use manual verification".
