       - Call match_documents via db.execute(sql`...`) with threshold 0.7, top 5 chunks, optional state filter
       - Return concatenated content strings, or empty string if no matches
       - If embed() fails (no OPENAI_API_KEY), return empty string with console.warn (graceful degradation for dev)

    4. Create src/ai/prompts/chatbot-system.ts:
       - Export `CHATBOT_SYSTEM_PROMPT({ context, listingState }: { context: string; listingState: string }): string`
       - System prompt structure (derived from docs/legal/ai-guidance-taxonomy.md):
         - Role: "You are a real estate information assistant for RealEstateHunter"
         - CONTEXT FROM KNOWLEDGE BASE: {context}
         - STATE: {listingState}
         - PERMITTED: factual property info, general process explanations, standard next steps, comparable sales data, showing scheduling
         - PROHIBITED: legal advice, contract interpretation, legal entitlements, litigation strategy, specific offer price recommendations, investment recommendations
         - DISCLAIMER: exact text from ai-guidance-taxonomy.md, appended to any transaction-topic response
         - ATTORNEY REFERRAL: trigger patterns (contract interpretation, cancellation rights, liens, title defects, legal remedies, fraud) — do NOT answer, instead refer to attorney in {listingState}

    5. Create src/ai/rag/seed/seed-knowledge.ts:
       - Script that reads docs/legal/ai-guidance-taxonomy.md, docs/legal/state-compliance-classification.md, docs/legal/upl-guardrail-document.md
       - Chunks each document into ~500-token pieces with overlap
       - Embeds each chunk using text-embedding-3-small
       - Inserts into knowledge_chunks table with source and state metadata
       - Runnable via: `npx tsx src/ai/rag/seed/seed-knowledge.ts`
       - Include a check: skip if chunks already exist for a given source
