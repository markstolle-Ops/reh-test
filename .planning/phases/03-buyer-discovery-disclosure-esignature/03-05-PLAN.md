  <action>
    1. Create src/services/signatures/signwell.ts:
       - SIGNWELL_API_KEY from process.env.SIGNWELL_API_KEY
       - SIGNWELL_BASE = "https://www.signwell.com/api/v1"

       - createDocumentForSigning(opts: { pdfBase64?: string; templateId?: string; signers: Array<{ name: string; email: string; role: string }>; name: string; listingId?: string; disclosureFormId?: string }):
         POST to ${SIGNWELL_BASE}/documents with x-api-key header.
         Body: test_mode (true unless production), files (if pdfBase64), template_ids (if templateId), recipients mapped from signers (id: crypto.randomUUID(), name, email, placeholder_name: role, send_email: false), embedded_signing: true.
         After success: insert signatureEnvelopes row (id: crypto.randomUUID(), signwellDocumentId: response.id, listingId, disclosureFormId, status: "pending").
         Return { envelopeId, signwellDocumentId, recipients }.

       - getDocumentStatus(signwellDocumentId: string):
         GET ${SIGNWELL_BASE}/documents/${signwellDocumentId}
         Return { status, recipients, audit_trail }.

       - getEmbeddedSigningUrl(signwellDocumentId: string, recipientId: string):
         Return the embedded_signing_url from the document's recipient object. (Fetched via getDocumentStatus.)

       - processWebhookEvent(payload: SignWellWebhookPayload):
         Switch on event_type:
         - "document_completed": update signatureEnvelopes set status="completed", auditTrail=JSON.stringify(payload.document.audit_trail), completedAt=new Date()
         - "document_declined": update signatureEnvelopes set status="declined"
         Match by signwellDocumentId from payload.document.id.

    2. Write comprehensive tests in src/services/signatures/signwell.test.ts. Mock global fetch for all HTTP calls. Mock the db module for database operations. Verify:
       - Correct URL and headers
       - test_mode flag logic
       - Multi-signer recipient mapping
       - Webhook event processing for both completed and declined
  </action>
